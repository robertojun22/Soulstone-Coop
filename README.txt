SOULSTONE COOP - co-op for Soulstone Survivors: local (same PC) and online (Steam), up to 4 players
====================================================================================================

WHAT IT IS
Soulstone Coop turns Soulstone Survivors into a co-op game. Play with 2 to 4 heroes, on the same PC, over Steam
with friends, or both at once (for example 2 players on one PC + 2 on another). Each player has their own hero,
controller, health and skill bar, cards and level-ups. Your saves are not touched.
Recommended: 2 players. 3 and 4 work, but with many enemies the game can get heavy.

FEATURES
- Local co-op: each player joins with their own controller (keyboard and mouse count as one player).
- Online co-op over Steam: create a room, invite friends through Steam and play together. The host runs the match,
  so enemies, bosses, events, chests and the host's sigil and difficulty are the same on every PC.
- Camera: split screen that follows the players (2 players), fixed split, or a shared "leash" screen that zooms out.
- Each player in their own color (P1 blue, P2 red, P3 green, P4 pink): damage numbers, crosshairs, health bars,
  minimap icons and level-up cards.
- Shared experience bar; every player picks their own cards on their turn. Titan cards go to everyone.
- Shared extra lives and revive: stand in a downed ally's zone to bring them back. The match ends only when
  everyone is down.
- Difficulty scaled for the number of players (more enemies, tougher elites, lords and bosses), plus a smart enemy
  pace that keeps the action fair.
- Co-op options in the game's Options menu ("Co-op" tab), with an explanation on every row.
- All the mod's texts in the game's 13 languages.

REQUIREMENTS
- Windows, with Soulstone Survivors from Steam.
- BepInEx 6 IL2CPP. It already comes in the full package: you don't need to download it.
- Internet on the FIRST launch after installing (BepInEx prepares its files; that launch takes 1 to 3 minutes on a
  frozen screen, which is normal).
- Online: every player needs the mod at the SAME version, and Steam running.

WHICH FILE TO USE
- SoulstoneCoop-<version>-full.zip: the mod + the right BepInEx. Use it to install and to update by hand.
- SoulstoneCoop-<version>-mod-only.zip: only the mod, for mod managers (Thunderstore format).

HOW TO INSTALL
1. In Steam: right-click Soulstone Survivors > Manage > Browse local files.
2. Extract ALL the contents of the full zip INTO that folder, keeping the folders and overwriting files.
   Updating works the same way; your settings are kept.
3. Start the game from Steam as usual and wait for the first launch to finish.
Do not update BepInEx yourself: the 5.4 version from the BepInEx GitHub page never works with this game. If the mod
disappears, extract the full package again.

HOW TO PLAY
- Local: on the main menu open "Co-op". Each player presses A (or Enter on the keyboard) to join; P1 confirms with
  START (or Enter). Everyone picks a hero on their turn.
- Online: on the "Co-op" screen the host presses Y (or O on the keyboard) to create the room and Y (or O) again to
  invite a friend through Steam. The friend accepts the invite and both pick their heroes.
The README inside each package has the full details, what's new in that version and the known issues.

SAFETY
- Local co-op does not use the internet. Online co-op only uses Steam's own network while you are in an online room;
  the mod opens no ports by itself.
- The mod does not edit saves. It only writes its own config file and logs.
- Only download from people you trust: BepInEx loads any DLL placed in BepInEx\plugins.

REPORTING A PROBLEM
Send the file BepInEx\LogOutput.log right after closing the game and say what happened, how many players there were
and whether it was local or online.
